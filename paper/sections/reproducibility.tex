\section{Reproducibility}
\label{sec:repro}

The simulator (\texttt{model/elevator\_sim.py}), the experiment runner (\texttt{model/run\_experiments.py}),
all result tables (\texttt{results/*.csv}), and these figures are in the project repository. Running
\texttt{python run\_experiments.py} with 60 replicates regenerates every table and figure.
